# Examples

The runnable example scripts that originally motivated this library --
Delphes ttbar/LLP event displays, vertex-pileup displays, the discussion-demo
prototypes (non-linear scaling, filterable gallery, displaced-track
highlighting, ...) -- live in the companion paper repository's `codes/`
directory, not here. This directory is reserved for small, self-contained
examples built directly on the `tracehep` public API (see the README
quickstart) as the package matures.
